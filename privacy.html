Privacy policy

Last updated: 20 October 2026

GTAvods uploader is a private tool used only by the owner of the GTAVOD YouTube channel to upload short video clips to that channel. It has no other users.

What it accesses

With the owner's permission, given through Google's sign-in, it uses the YouTube Data API to upload videos to the owner's channel and to read that channel's name. It does not read, collect or store data about anyone else.

How the data is kept

The sign-in token Google issues is stored only on the owner's own server and is used only to upload the owner's videos. It is never shared, sold or sent to anyone other than Google.

YouTube and Google

This tool uses YouTube API Services. By using it you agree to the YouTube Terms of Service, and Google's handling of data is described in the Google Privacy Policy. Access can be removed at any time at myaccount.google.com/permissions.
